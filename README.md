# 📚 Sistema de Cálculo de Notas - Dart

Este projeto em Dart é uma aplicação de terminal simples para registrar estudantes, associar suas notas e calcular a média individual e da turma. Ele serve como um exemplo educacional de entrada e saída em terminal, manipulação de mapas e listas, e uso de funções.

## 🚀 Funcionalidades

- Registrar estudantes e suas notas.
- Consultar a lista de estudantes cadastrados.
- Calcular a média individual de cada estudante.
- Calcular a média geral da turma.
- Interface em modo texto via terminal.

## 📋 Menu Principal
Ao executar o programa, você verá o seguinte menu:
```
Escolhe uma opção:
 1 - Registrar estudante
 2 - Consultar estudantes
 3 - Consultar média dos estudantes e da turma
 4 - Sair
```
